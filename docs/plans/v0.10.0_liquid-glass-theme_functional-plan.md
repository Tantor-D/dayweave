# v0.10.0 / liquid-glass-theme 功能计划

## 文档的关键结论

用户已确认给现有工作台新增 Liquid Glass 液态玻璃主题。新增可切换的浅色主题及本地背景图片自定义，覆盖工作台、待办、统计与公共弹窗，保留原有主题及业务行为。

- 按用户最新反馈采用简洁白色背景和清透材质，去掉彩色环境光及磨砂模糊；以弧面高光、边缘明暗折射感、悬浮胶囊控件和柔和按压反馈表现液态玻璃。
- 选择「液态玻璃 Liquid Glass」后保存偏好，刷新仍保留；不改变已有默认主题。
- 采用网页可实现的清透表面与边缘高光近似效果，不承诺原生实时光学折射。

## 范围与验收

主题选择沿用现有入口及编辑期间的切换锁定。主题切换不得修改任务、排期和其他偏好。保留任务颜色、键盘焦点、现有窄屏横向看板交互，兼顾减少动画、减少透明度和不支持背景模糊的浏览器。

验收包括六主题切换、新主题刷新持久化、三个主页面、任务弹窗与统计弹窗、窄窗口可达性以及完整自动测试和生产构建。

## 已确认的背景自定义

用户选定参考③ iPhone 控制中心、④透明桌面图标的材质，并要求支持上传背景图片及调节图片模糊程度。仅液态玻璃主题显示「自定义」入口，保留白色默认背景。

- 支持 JPG、PNG、WebP 本地图片，居中覆盖背景；选图自动缩放压缩，源文件最大 12MB。
- 背景图片模糊范围 0–40px，即时预览；不改变玻璃控件本身的模糊程度。
- 保存后刷新保留；取消、关闭和 Escape 撤销草稿，移除图片恢复白底，恢复默认先预览。
- 编辑、上传处理及保存期间避免冲突操作；图片失败和保存失败明确提示，不覆盖原配置。
- 验收上传、模糊调节、刷新保留、取消、移除、失败、窄屏和其他主题隔离。
