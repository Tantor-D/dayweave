# v0.8.0 / claymorphism-theme 技术方案

## 文档的关键结论

沿用 v0.6.0 已确认的共享应用能力与独立呈现目录设计，新增第三个风格家族。应用控制器保持存活，业务数据结构与业务操作不变，仅扩展当前主题偏好取值。

- `presentations/claymorphism` 独立维护页面、主题配置和工作台／统计样式，不导入其他家族。
- 公共控件通过既有 Appearance 契约取样式，待办通过限定主题作用域的样式适配；无需新依赖。
- 保留进入本轮前的待办相关未提交修改，按本轮差异隔离提交；截图与验收脚本仅放已忽略的 `.artifacts/claymorphism/`。

## 实施步骤

1. 新增家族页面和样式，沿用固定任务栏与详情浮层布局，补齐公共控件样式槽位。

3. 完成待办材质适配、状态提示、焦点、交互反馈和窄窗样式；保留紧凑任务列表与颜色语义。
4. 扩展偏好持久化测试与三家族隔离／样式契约测试，更新版本和 README。
5. 自动验证与隔离浏览器验收，检查实际差异后仅本地提交本迭代，不推送。

## 验证方法

- 执行全量测试、类型检查、生产构建；验证四个主题持久化与非法主题拒绝，业务数据哈希及其他偏好不变。
- 浏览器使用独立端口、独立 data/local 目录，禁止指向正式数据；验证切换与刷新、切换失败与编辑锁定、全部主页面与弹窗。
- 检查桌面和窄窗布局、横纵时间轴、拖拽和拉伸、待办编辑与日期变更、焦点及减少动态效果。
- 无 ROADMAP，不创建 PROGRESS。保留既有未提交改动，混合文件只暂存本轮增量。
