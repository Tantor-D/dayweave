# v0.3.0 task-workbench 技术方案

## 文档的关键结论

沿用既有 React／TypeScript／Fastify 与文件存储。schemaVersion 3 增加标签颜色和颜色优先级，任务状态简化为 todo/done；偏好增加每日时间窗口与复制继承开关，旧工作区和历史仍可迁移恢复。本轮以 8c5a930 为基线，开始时工作区与暂存区干净，无 ROADMAP.md。

## 设计与改动

- 领域：Tag.color、colorPriority；task.update 增加 propagateTags 布尔意图，仅显式为 true 时同步后代。本次删除标签从后代移除，其余父标签合并。新建／换父节点按当前继承偏好复制，所有入口共用服务端实现。
- 迁移：冻结 v2 校验，v1→v2→v3，旧 in_progress→todo，补齐稳定默认颜色与优先顺序；保留原始版本备份和旧历史，失效旧提案。偏好迁移保留已有筛选并补充默认值。
- 网页：TaskFields 替换父节点 select 为可搜索候选；统一保存入口显示后代标签确认对话框，固定保存基准版本。标签管理提供颜色和优先级，设置页增加工作台偏好。
- 拖拽：扩展既有指针拖拽，任务列表目标生成 parentId 更新，显示归属预览，禁止自身／后代目标；服务端继续防循环。
- 时间轴：每日窗口统一坐标转换，裁切展示范围与拖选边界；同日横向左右共享有上限的外层高度，左右内部内容分别滚动。纵向未定时区有高度上限。
- 筛选：左侧日期快捷项仅控制任务列表，中央看板仍按其自己的日期范围显示；列表补齐祖先上下文但不改变筛选命中数。
- 展示：颜色由标签优先级稳定选取，完成淡化；删除底部提示及左侧安排计数。

## 实施与验证顺序

1. 保存计划，使用隔离数据复现并测量横向高度错位。
2. 实现 schema／迁移／状态／继承规则与专项测试。
3. 实现任务字段、确认对话框、标签和偏好设置、列表筛选与拖拽。
4. 实现时间窗口及布局修复，复跑原始测量和鼠标交互。
5. 全量自动测试、构建和隔离浏览器验收，更新文档与版本号，本地提交；不推送。

测试与浏览器产物置于 /tmp 或已忽略 .artifacts/，不修改真实数据用于验收。启动日常服务前确认配套后端同步更新。


## 实施结果

- 布局根因：右侧高度仅由定时任务层数决定，左侧未定时内容按自身高度撑开，且两侧没有统一上限。现在共享有上限的外层行高，内部保留足够内容高度并滚动，避免卡片无限缩小。
- 复现脚本 .artifacts/layout-v3.js 与最小化脚本 layout-minimize.js 在修复前捕获左右高度差；修复后同一测量为 284px／284px，左右 scrollTop 均可变化。
- 70 项全量自动测试、类型检查及生产构建通过；浏览器验证完整手工流程、颜色优先级、状态淡化、继承及删除确认、拖拽归属、筛选和每日时段坐标。自定义时段下已有排期移动／拉伸仍保持正确时长和持久化。
- 文档、包版本与启动版本标识更新为 v0.3.0。正式工作目录的数据未用于验收；正常服务启动会按已验证机制升级其旧数据。
