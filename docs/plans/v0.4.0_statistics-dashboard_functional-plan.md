# v0.4.0 statistics-dashboard 功能计划

## 文档的关键结论

新增独立全宽统计视图，将时间轴中已发生的定时安排视为投入记录。提供固定布局、轻配置、图表及可核对明细；不新增计时器或自由布局编辑器。

## 已确认口径

- Asia/Shanghai，自然日拆分，左闭右开，今日截至当前时间，未来不计；未定时安排不计时，已完成、未完成及归档均参与，不受工作台显示筛选影响。
- 未带“个人”标签的任务算工作；任务自身标签决定分类，不动态继承。工作、个人各自合并重叠区间；两者可能重叠，不能直接相加作为总投入。
- 加班为00:00–06:00和21:00–24:00，午休占用为12:30–14:00。
- 至少两个不同工作任务重叠的时长除以工作时长为并行占比；同任务重叠先合并，父子任务独立参与。
- 首次工作取06:00后首个工作时段；跨06:00取06:00，缺失不参与平均。
- 标签内部去重，标签之间可重叠。历史随当前任务、安排及标签重算。
- “时间花在了哪里”包含“无标签”分类，统计任务自身未设置标签的已发生定时用时，分类内部重叠去重，与已有标签一起按时长排序、分页；零用时不展示。

## 页面与配置

- 工作台／统计切换，返回保留工作台状态；默认近30天，可选本周、本月、自定义含首尾日期。
- 六张概览卡：工作、加班、午休占用、并行占比、平均首次工作、个人；补充工作记录天数和日均工作。
- 每日普通工作／午休／加班堆叠柱，首次工作散点及平均线，单／多任务分布，标签横条排行。
- 固定个人分析及可选标签分析：时长、占全部去重时长比例、涉及天数、每日趋势。无个人标签时提示，不自动创建。
- 每日表格展示首次、最后工作及各时长、并行占比；日期展开任务时段。
- 保存日期、关注标签、图表显隐；概览、个人与明细固定保留。恢复默认展示。深浅主题、窄屏及键盘数值说明可用。

## 验收与进度

覆盖时间边界、跨日／月／年、重叠、多标签、空数据、偏好兼容及持久化；全量测试、类型检查、构建和隔离浏览器验证。22:00–次日02:00应计4小时加班，两个工作任务同时一小时应计1小时工作和100%并行。

## 白屏修复与折线趋势补充

当前开发服务出现新版前端与旧后端并存：偏好响应缺少 statistics，直接覆盖默认值后进入统计会抛出 range 读取错误。前端读取及保存偏好统一补齐缺失的统计默认值，并同步重启工作台后端；回归覆盖旧服务响应。

新增按日折线趋势，指标切换为工作、加班、午休占用、个人时长、并行占比与首次工作时间，一次显示一个指标，分别使用小时／百分比／时刻坐标。沿用全局日期范围、既有统计口径和图表显隐；缺失的占比及首次工作日期断开连线，零时长保留零点。首次工作和标签既有图表保留。指标切换为页面临时状态，不扩充持久化配置；新增图表显隐键 trend 由原偏好数组承载，旧偏好自然默认显示。

验收：旧后端白屏复现转绿，折线切换／断点／焦点数值／显隐正确，类型检查、全量测试及构建通过后记录结果。补充已完成：原日常环境点击统计的白屏已复现并修复，旧后端运行时也可正常打开；工作台开发服务已同步重启至当前代码。83项全量测试、类型检查与生产构建通过；额外验证趋势显隐保存的专项测试通过。浏览器验证六类折线、缺失日期断线、焦点数值、显隐刷新保持、空态及深浅主题／390px窄屏。此次局部修复与图表补充保留在工作区，未另行提交或推送。
