# v0.4.0 statistics-dashboard 功能计划

## 文档的关键结论

新增独立全宽统计视图，将时间轴中已发生的定时安排视为投入记录。提供固定布局、轻配置、图表及可核对明细；不新增计时器或自由布局编辑器。

## 已确认口径

- Asia/Shanghai，自然日拆分，左闭右开，今日截至当前时间，未来不计；未定时安排不计时，已完成、未完成及归档均参与，不受工作台显示筛选影响。
- 未带“个人”标签的任务算工作；任务自身标签决定分类，不动态继承。工作、个人各自合并重叠区间；两者可能重叠，不能直接相加作为总投入。
- 加班为00:00–06:00和21:00–24:00，午休占用为12:30–14:00。
- 至少两个不同工作任务重叠的时长除以工作时长为并行占比；同任务重叠先合并，父子任务独立参与。
- 首次工作取06:00后首个工作时段；跨06:00取06:00，缺失不参与平均。
- 标签内部去重，标签之间可重叠。历史随当前任务、安排及标签重算。

## 页面与配置

- 工作台／统计切换，返回保留工作台状态；默认近30天，可选本周、本月、自定义含首尾日期。
- 六张概览卡：工作、加班、午休占用、并行占比、平均首次工作、个人；补充工作记录天数和日均工作。
- 每日普通工作／午休／加班堆叠柱，首次工作散点及平均线，单／多任务分布，标签横条排行。
- 固定个人分析及可选标签分析：时长、占全部去重时长比例、涉及天数、每日趋势。无个人标签时提示，不自动创建。
- 每日表格展示首次、最后工作及各时长、并行占比；日期展开任务时段。
- 保存日期、关注标签、图表显隐；概览、个人与明细固定保留。恢复默认展示。深浅主题、窄屏及键盘数值说明可用。
