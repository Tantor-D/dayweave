# v0.6.0 / neobrutalism-theme 功能计划

## 文档的关键结论

用户已确认一个产品内核、多套独立界面的方案，并授权开发。新增浅色 Neobrutalism，保留晨光玻璃和夜色玻璃，所有界面提供相同业务功能。

- 不同风格独立维护页面入口、布局和视觉文件，深浅玻璃属于同一风格家族。
- 主题选择持久化，不改变任务、排期、标签和统计数据。
- 未保存编辑不能因切换丢失；本版在详情或编辑弹窗打开、保存或拖拽期间禁用风格切换，先关闭编辑区域再切换。

## 范围与验收

新风格使用暖白背景、黑色粗线、硬阴影、鲜粉与明黄色块、大号标题；覆盖工作台、统计、设置、背景、回望及弹窗。保留任务颜色语义与原有完整业务流程。玻璃界面不被新样式覆盖。

验收三个选择项持久化、旧偏好兼容、同一任务在不同界面可访问、横纵时间轴与窄窗口可用；类型检查、完整测试及构建通过。隔离数据进行浏览器验收，不操作正式数据。
