# v0.5.0 cli-ai-workflow 功能计划

## 文档的关键结论

AI 协作改为 CLI 对话，修改前展示差异并经聊天确认，日记允许全库检索后按需读取。网页保留手工管理与历史，不再配置或调用模型。

## 目标与范围

以 Codex 为主要 AI 入口，移除网页 AI 聊天和模型配置；保留看板、手工编辑、背景、日记、提案与历史。仅访问工作台内的每日与独立反思，不接入外部应用。Claude Code 与 Gemini CLI 提供共享规则入口，本轮不承诺实机验收。

## 关键流程与验收

AI 每轮读取最新 context 和 schema，检索全部日记并按需读取正文；通过 preview 展示真实差异，用户在聊天明确确认后由 CLI confirm 保存。信任 CLI 识别确认，服务端不独立证明真人身份。普通外部 submit 始终等待确认，旧自动接受设置失效。

冲突后重建提案并重新确认；相同请求重试不重复保存。多目标独立报告结果。无模型密钥时完成隔离数据的读取、检索、提案、确认和网页查看流程，网页原有手工功能保持可用。

## 实施结果

已完成 CLI 确认、提案读取、日记分页检索、统一规则入口及网页模型能力移除。85 项自动测试、类型检查与构建通过；隔离数据验证 CLI 保存同步到网页、历史确认来源及日记上下文，网页背景编辑、回望、统计、提案、窄窗设置可用。Claude Code、Gemini CLI 未实机验收。验收产物留在 /tmp，不纳入 Git；无 ROADMAP.md，未创建 PROGRESS.md。
