# v0.7.0 todo-list 功能计划

## 文档的关键结论

新增与工作台、统计并列的待办页面，专门按任务自身的分配日期展示任务。日期记录与定时时段严格隔离，沿用已有任务及保存机制。

- 今日、3 日、7 日包含今天；本周为周一至周日。多日期任务分别出现。默认选择 3 日，不包含父任务自身日期，并显示已完成任务。
- 先按日期与筛选条件命中任务，再补齐全部祖先并按树结构展示。默认叶节点参与命中；「包含父任务自身日期」开启后，非叶节点也按自身日期参与命中。祖先始终显示，不继承子任务日期。
- 过期未完成日期记录集中到可折叠的过期组；未分配日期组默认收起；已完成默认显示、可切换隐藏。仅有定时时段也视为未分配日期。
- 支持完成勾选、行内改名、任务行直接拖拽归属、设为一级任务及跨日期拖拽，移除父任务下拉框和独立归属按钮。
- 跨日期拖拽只修改整棵子树中叶节点的对应日期；非叶节点自身日期、其他日期和定时时段保持原样，目标日期已存在时合并为一条。
- 从工作台时间条新建任务时，同时保存具体时段和开始日期的未定时安排，使任务能在待办页对应日期显示；跨午夜只添加开始日期。关联已有任务仍仅增加所选安排。

## 交互与验收

每个日期组、过期组及未分配组独立展示完整祖先树，沿用工作台左侧树顺序和层级缩进。仅作路径的父节点标注「层级节点」，不显示日期输入，不给自己新增日期；跨日拖拽带动叶节点对应日期移动。同一父任务在组内既命中又为祖先时不额外重复，过期任务的多个真实日期记录保留。计数仅包含实际命中记录。

日期组区域接收改期拖拽，任务行直接接收归属拖放。拖到另一日期的任务行，同时修改归属和叶节点日期；拖到顶部区域设为一级任务并保留日期。整棵子树保留内部层级，归属和日期一次保存。日期输入继续支持精确改单条日期。

三个主题任务标题统一 16px，缩小上下留白，常规单行实测约 37px。

验收覆盖三种主题、日期范围与周界、多日期与去重、过期折叠、未分配与完成筛选、父任务自身日期、循环归属拒绝及保存失败。使用隔离数据，验证改期前后定时记录完全一致；运行全量测试、类型检查、构建与浏览器验证。

## 完成状态

本迭代功能已完成，自动测试及隔离浏览器验收通过。日期、父任务显示、过期收纳、重复日期合并和时间条隔离均按已确认规则生效。

## 父任务自动完成设置

工作台设置增加「所有子任务完成后，自动完成父任务」，默认开启以保留原行为。关闭后子任务全部完成不会自动完成父任务，可手动完成或重新打开父任务；手动完成父任务仍完成其全部后代，重新打开子任务仍重新打开已完成祖先。设置本身不修改已有任务状态，后续操作及新提案使用保存的设置；已生成提案保持其原预览结果。
