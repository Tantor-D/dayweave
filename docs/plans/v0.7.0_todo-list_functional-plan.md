# v0.7.0 todo-list 功能计划

## 文档的关键结论

新增与工作台、统计并列的待办页面，专门按任务自身的分配日期展示任务。日期记录与定时时段严格隔离，沿用已有任务及保存机制。

- 今日、3 日、7 日包含今天；本周为周一至周日。多日期任务分别出现。
- 默认仅显示叶节点；开启显示父任务后全部平等展示，不补祖先标题，不继承子任务日期。
- 过期未完成日期记录集中到可折叠的过期组；未分配日期组默认收起；已完成默认隐藏、可切换显示。仅有定时时段也视为未分配日期。
- 支持完成勾选、行内改名、父任务选择、拖拽归属、设为一级任务及跨日期拖拽。
- 跨日期拖拽替换当前日期，其他日期和定时时段保持原样；目标日期已存在时合并为一条。

## 交互与验收

日期组平铺任务，所属路径用于辨识。日期组区域接收改期拖拽；每行独立的归属目标接收设为子任务拖拽，避免同一手势同时改日期和归属。提供日期输入和父任务选择作为拖拽替代操作。

验收覆盖三种主题、日期范围与周界、多日期与去重、过期折叠、未分配与完成筛选、父任务自身日期、循环归属拒绝及保存失败。使用隔离数据，验证改期前后定时记录完全一致；运行全量测试、类型检查、构建与浏览器验证。

## 完成状态

本迭代功能已完成，自动测试及隔离浏览器验收通过。日期、父任务显示、过期收纳、重复日期合并和时间条隔离均按已确认规则生效。
