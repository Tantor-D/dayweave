# v0.8.0 / claymorphism-theme 功能计划

## 文档的关键结论

新增「黏土拟态 Claymorphism」浅色主题，与晨光玻璃、夜色玻璃、新粗野主义并存。用户已确认视觉方案与实施范围，并授权开发。

- 淡薰衣草背景、奶白面板、紫色主操作、柔粉辅助色，使用大圆角、内高光、内暗影和带色外投影。
- 覆盖工作台、待办、统计和全部弹窗；保留任务颜色语义、已有操作布局及待办 16px 标题与紧凑行距。
- 选择持久化；切换不改变业务数据，不丢失未保存编辑。首版仅浅色，无新增在线字体、插画或装饰动画。

## 范围与交互

主题标识为 `claymorphism-light`。固定任务栏、时间轴及独立详情浮层沿用已有操作方式，待办日期分组采用柔软卡片。统计图表与任务状态继续使用可辨认的语义颜色。

按钮悬停轻微上浮、按下压缩，输入框使用内凹阴影，焦点可见并支持减少动态效果。列表和时间条采用轻阴影，避免遮挡文字或影响拖拽。

详情、编辑弹窗、待办编辑、统计编辑、拖拽和保存期间沿用现有切换锁定；主题保存失败保持原视图。

## 验收标准

四个主题选择与刷新持久化通过，旧偏好兼容且非法主题被拒绝。新主题覆盖三个主页面、背景、回望、历史、标签、提案、设置及相关弹窗，原主题保持原样。

使用隔离数据检查任务编辑与完成、待办改期、横纵时间轴拖拽与拉伸、桌面和窄窗口、键盘焦点及减少动态效果；全量测试、类型检查与构建通过。
