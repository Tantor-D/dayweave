# v0.3.0 task-workbench 功能计划

## 文档的关键结论

本迭代完善任务组织、颜色辨识、日期筛选与时间轴布局。用户已确认以下八项功能及继承、筛选、内部滚动规则；沿用本地文件、统一审批和历史恢复。

- 父任务可输入检索，排除已完成、归档、自身及后代；已有归属仍显示。
- 标签可配置颜色和颜色优先顺序；多标签取优先级最高者，完成后变浅。
- 横向每一天左右等高，最大为常规行高两倍，超出内部滚动；纵向只限制未定时区高度。
- 设置每日显示起止时间，默认 00:00–24:00；仅影响显示与拖选，保留范围外安排。
- 左侧移除安排次数，支持将任务拖到另一个任务成为子任务；复制继承父标签默认开启。
- 状态只保留未完成和已完成，旧进行中迁移为未完成，沿用完成上下联动。
- 左侧增加全部、今天、本周、未来三天、未来七天，按排期相交筛选并保留必要祖先。
- 移除主栏底部保存位置与操作提示。

## 已确认行为

- 新建或更换父节点时，继承开启则复制并合并父标签；子任务可随后独立修改，不反向修改父节点。
- 父节点标签变化时弹窗选择“仅此任务”或“应用全部后代”，可取消保存。应用时合并父节点当前全部标签，保留后代独有标签；本次从父节点删除的标签也从后代删除，弹窗明确列出。
- 今天与未来三／七天包含今天，本周为周一至周日；未排期任务只在全部下直接展示。祖先仅作路径上下文，不额外把无关祖先排期纳入筛选结果。
- 每日范围要求开始早于结束，可到 24:00，不支持反向区间；跨午夜排期按每日窗口裁切显示，数据不变。
- 标签颜色优先级数值越小越优先；同值按标签顺序和 ID 稳定决定；无标签使用默认主题色。归档标签不参与颜色决策。
- 横向常规行高 142px，上限 284px；大量未定时与定时内容保持可滚动访问，不通过无限缩小卡片实现上限。

## 验收

1. 搜索父节点、键盘选择与已完成过滤有效，拖拽归属防循环且不破坏时间轴拖拽。
2. 继承开关、合并／删除确认、取消、子节点独立修改与状态迁移通过领域和网页验证。
3. 多标签颜色优先级与完成淡化在横纵、未定时区一致，刷新保持。
4. 通过真实页面测量复现截图错位，修复后左右等高且不超过上限；溢出内容可滚动。
5. 自定义时间窗口下刻度、拖选、移动、拉伸和跨日显示正确；范围外排期保留。
6. 日期筛选覆盖周界、跨日及未排期祖先；简化文案和状态无残留。
7. 全量测试、构建、隔离浏览器验证后本地提交，不推送。真实模型接口不作为本轮验收前提。

## 进度

八项功能均已实现。70 项自动测试全部通过，类型检查和生产构建通过；隔离浏览器验证父任务搜索、已完成排除、标签颜色与完成淡化、继承开关、合并／删除确认、取消不写入、拖拽归属、日期筛选、时间窗口拖选以及既有排期移动／拉伸。

布局实测从左右约 327px／142px 的错位，修复为左右均 284px；大量定时／未定时内容均可内部滚动。纵向未定时区高度 144px，滚动内容保持可访问。深浅主题及 850px 窄窗设置页可用。

旧数据通过备份与历史机制迁移；未调用真实模型。无 ROADMAP.md，未创建 PROGRESS.md。

## 默认日期、时间轴层级与过期任务补充

普通新建任务默认安排日期为今日，允许修改日期，不设置起止时间；从时间轴创建仍采用选中安排。横向时间轴每一天左侧的未定时区域默认只显示一级任务，通过箭头逐级展开当天的子任务；当天无安排的祖先仅作为层级标题，不能拖动成已有安排。展开和收起不修改任务或排期，保持左右等高和内部滚动。

任务列表的今日、本周、未来三天和未来七天筛选补入过期未完成任务，仅影响左侧任务列表。过期按最后一次安排的结束判断：日期安排早于今日，定时安排不晚于今日零点结束；若有今日或未来安排则不算过期，无安排任务不算过期。沿用既有状态、标签、归档筛选，并保留命中任务的祖先。

已完成：18项相关测试、类型检查与构建通过；隔离浏览器验证默认日期保存、三级展开／收起、不会误开新建弹窗、四类日期筛选、未来重排排除以及时间轴不受筛选影响。左右等高实测均为142px。此次局部补充不新增版本，不提交或推送；验收产物位于已忽略的 .artifacts/sidebar-update/。

关联已有任务补充：时间轴新建窗口中的候选按任务树顺序和层级缩进展示，搜索命中子任务时保留其祖先；已完成、已归档任务及不可用分支不参与选择。候选仅显示任务名称和层级，移除“任务 · N 次安排”副标题并缩小上下留白，保持列表紧凑。选择只增加安排，保留任务原有父子关系。
