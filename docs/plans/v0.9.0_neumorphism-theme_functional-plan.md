# v0.9.0 / neumorphism-theme 功能计划

## 文档的关键结论

新增「柔光拟态 Neumorphism」浅色主题及专属配置抽屉，用户已确认视觉、配置范围和入口位置并授权实施。现有四主题与业务操作保留。

- 默认采用柔光拟态主题与晨光暖白 #f3f3f8，强调色 #365c87，圆角 13px、距离 11px、阴影强度 22%、柔和度 11px、左上光源；输入框和按下状态内凹。
- 主题选择器旁显示「拟态设置」，仅该主题可见；右侧抽屉，窄窗口全宽。
- 配置底色、强调色、圆角、凸起距离、阴影强度、柔和度、四角光源，以及一级任务材质（凹陷／凸起，默认凹陷）。实时预览，保存持久化，取消、关闭或 Escape 恢复原值；恢复默认先预览。

## 范围与验收

覆盖工作台、待办、统计和公共弹窗。保留任务颜色、紧凑列表、键盘焦点和减少动画支持。抽屉使用期间禁止主题切换及背景编辑，保存失败保留草稿并提示。

旧偏好自动采用默认拟态配置；非法参数拒绝保存。配置仅影响拟态主题。验证保存与刷新、取消与关闭、重置、失败、窄窗口、编辑与拖拽回归。

## 默认工作台配置

按当前已保存配置作为新安装默认值：单日、纵向、隐藏未定时、面板宽度 352.734375px，时间范围 10:00–21:30；显示已完成、隐藏归档，无任务或标签过滤，启用子任务标签继承，关闭父任务自动完成。统计默认本周，不固定历史自定义日期。既有偏好文件保留已保存值，旧字段迁移兼容原行为。
