# v0.2.0 focus-workbench 功能计划

## 文档的关键结论

本迭代在 v0.1.0 本机工作台上完善日常安排入口和视觉体验，沿用真实文件、统一 harness、审批与历史恢复。已明确的工作是时间轴点击新建／关联任务，以及保持整体布局的极简玻璃深浅主题升级；多选标签已明确，是否同时替代原有分类尚待确认。

- 时间轴空白处可直接安排新任务或已有任务；仅日期区域提供相同入口。
- P0–P4 应是普通预置标签，任务可同时带有工作、个人、运动等自定义标签。
- 后续统计大面板单独安排；本迭代不将计划时长冒充实际专注时长。

## 范围与关键流程

### 点击安排

- 单日、多日、横向、纵向均支持点击空白处打开安排表单；点击已有块仍打开任务详情，拖拽结束不意外弹出新建表单。
- 点击位置按 15 分钟吸附，默认安排 60 分钟，可以修改起止时间并跨午夜；仅日期入口默认不设置时刻。
- 用户选择新建任务或搜索并关联已有任务。新建与排期在同一提案提交；关联仅添加排期，不复制任务。保留同日未定时去重与不限重叠规则。
- 取消不写数据；保存失败保留表单并提示。打开表单时绑定工作数据版本，过期时拒绝覆盖。

### 视觉更新

- 保留左侧任务、中央时间轴和可收起详情的布局。
- 雾白／石墨色背景，柔和环境色、半透明玻璃面板、细微高光与阴影，减少不必要边框和装饰性英文。
- 系统字体、清晰字号层级、适当留白；深浅主题均保留可读对比度和键盘焦点；减少透明度／动态效果时提供降级。

### 标签：待确认的边界

推荐统一替代优先级与分类：任务可多选标签，项目继续组织任务；旧优先级与任务原有／从项目继承的分类均迁移为任务标签。另一种选择是保留分类并新增标签。

此选择会改变项目分类继承、筛选及旧数据迁移，确认之前不实施相关数据变更。标签定义、网页编辑、筛选、AI/harness、历史恢复必须在同一契约下完成，不能只改显示文字。

## 后续统计面板方向

采用占据主要内容区的大面板，考虑任务新增／完成趋势、待办与进行中数量、未排期任务、日／周计划时长、按项目与标签分布。指标口径及具体范围在该阶段确认；当前数据只能反映计划安排与完成记录。
