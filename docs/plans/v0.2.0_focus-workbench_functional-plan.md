# v0.2.0 focus-workbench 功能计划

## 文档的关键结论

本迭代在 v0.1.0 本机工作台上完善日常安排入口和视觉体验，沿用真实文件、统一 harness、审批与历史恢复。已完成时间轴拖选新建／关联、统一任务树、多选标签，以及保持整体布局的深浅玻璃主题升级。

- 时间轴空白处可直接安排新任务或已有任务；仅日期区域提供相同入口。
- P0–P4 应是普通预置标签，任务可同时带有工作、个人、运动等自定义标签。
- 后续统计大面板单独安排；本迭代不将计划时长冒充实际专注时长。

## 范围与关键流程

### 拖选与点击安排

- 单日、多日、横向、纵向均支持点击空白处打开安排表单；点击已有块仍打开任务详情，拖拽结束不意外弹出新建表单。
- 拖选起止位置按 15 分钟吸附；单击默认安排 60 分钟，可以修改起止时间并跨午夜；仅日期入口默认不设置时刻。
- 用户选择新建任务或搜索并关联已有任务。新建与排期在同一提案提交；关联仅添加排期，不复制任务。保留同日未定时去重与不限重叠规则。
- 取消不写数据；保存失败保留表单并提示。打开表单时绑定工作数据版本，过期时拒绝覆盖。

### 视觉更新

- 保留左侧任务、中央时间轴和可收起详情的布局。
- 雾白／石墨色背景，柔和环境色、半透明玻璃面板、细微高光与阴影，减少不必要边框和装饰性英文。
- 系统字体、清晰字号层级、适当留白；深浅主题均保留可读对比度和键盘焦点；减少透明度／动态效果时提供降级。

### 任务树与标签（已确认）

- 取消独立项目与分类；每个任务为树中节点，根任务可以独立存在，子任务可继续嵌套。路径显示为“父任务 / 子任务”，父子关联不依赖名称。
- 旧项目变为根任务，原项目任务变为子任务；旧分类（含继承分类）及优先级变为普通标签，预置 P0–P4，任务可多选或不选标签。标签名称禁止包含 ASCII "/"；旧名称中的 "/" 迁移为全角 "／" 并保留原始备份。
- 完成父任务会完成全部后代；所有直接子任务完成时自动完成父任务并向上递推；重新打开后代、新增未完成子任务或移入未完成子任务时，已完成祖先变为进行中。归档节点仍参与完成规则。
- 不允许循环归属或悬空父节点。任务可调整父节点；归档祖先时默认隐藏其整棵子树。
- 时间轴左键按住拖动选取范围，松开打开新建／关联面板；15 分钟吸附，支持反向和跨日选择、Esc 取消。单击保留默认 60 分钟安排。
- 安排面板支持名称、说明、父任务、多选标签；关联已有任务可在面板编辑该任务。点击列表或时间块进入任务设置。

## 后续统计面板方向

采用占据主要内容区的大面板，考虑任务新增／完成趋势、待办与进行中数量、未排期任务、日／周计划时长、按项目与标签分布。指标口径及具体范围在该阶段确认；当前数据只能反映计划安排与完成记录。
