# v0.2.0 focus-workbench 技术方案

## 文档的关键结论

本迭代继续使用 React／TypeScript／Fastify 与 JSON／Markdown 真源，不引入新框架或存储。时间轴拖选、统一任务树、多选标签、编辑面板和 schemaVersion 2 迁移已实现；网页、AI 与 harness 共用领域校验与历史恢复。真实模型接口仍需用户配置后验证。

## 现状与已确认设计

- v0.1.0 基线为 aec7ed2；v0.2.0 点击安排及玻璃界面基线为 492649c。本轮开始时 main 工作区与暂存区干净。
- 用户确认：按住左键拖选时间、松开后打开新建／关联面板；取消项目和分类实体，使用可多层嵌套的任务树与普通标签。
- parentId 为唯一父子关系，根任务为 null；任务路径显示“父任务 / 子任务”。任务名称保持原文，标签名称禁止 ASCII "/"。
- P0–P4 为普通预置标签；任务可多选或不选标签，不保留单选优先级字段。
- 完成父任务完成所有后代；所有子任务完成自动完成祖先。重新打开子任务、新增或移入未完成子任务会将已完成祖先变为进行中。归档子任务仍参与完成规则。
- 全部子任务已完成的父任务不允许单独改为未完成，界面提示先重新打开具体子任务；不擅自重新打开所有后代。
- 无 ROADMAP.md，因此不创建 PROGRESS.md；沿用 v0.2.0，不因本轮开发另增版本。

## 模块与实现

### 领域模型

- types.ts、schema.ts 定义 Task.parentId、Task.tagIds 与 Tag；操作统一为 tag.create/update、task.create/update、placement.put/remove、text.write。
- operations.ts 校验标签引用、重复名称、父节点存在与无环关系，以及父子完成状态一致性。联动在同一提案中执行，完成事件按最终状态生成。
- tree.ts 提供祖先、路径和树序展示；筛选或归档祖先默认隐藏整棵子树，标签筛选仅作用于直接带有该标签的任务。
- AI 提示与 schema 同步新契约，明确完成联动可能影响同树其他任务；harness 继续使用服务端 schema 与统一提交接口。

### 数据迁移与恢复

- legacy.ts 只负责严格校验旧持久化结构；migration.ts 确定性转换 v1 快照。旧项目转为根任务，原项目任务保留原 ID、描述、排期、完成记录，并归属于对应根任务。
- 项目 ID 与任务 ID 冲突时生成稳定根任务 ID。旧分类与继承分类、优先级转为普通标签；同名标签合并，旧名称中的 "/" 转为全角 "／"。无原始时间信息的根任务使用未知时间标记，详情显示“创建时间未知”。
- 启动先恢复已有事务；只有可信快照与磁盘内容一致且可写时才迁移。先写入原始备份，再通过既有 prepared／committed 历史机制提交并增加 revision。
- 备份路径为 data/.history/changes/workspace-v1-<hash>.backup。旧历史不重写，恢复旧版本时转换为 v2；旧未提交工作区提案失效，需重新生成。
- 外部未采纳文件不覆盖；损坏或未知版本继续保留现场。迁移中断复用已有事务恢复机制。
- 旧偏好读取时将分类筛选映射为标签、项目筛选映射为根任务，保留其他偏好；后续偏好保存使用新格式。

### 网页交互

- TaskFields.tsx 复用于新建、安排和任务详情，支持名称、说明、父任务及多选标签；父任务候选排除自己与后代。
- 左侧展示缩进任务树，搜索与父任务选择使用完整路径；标签管理替代旧项目／分类面板。
- Timeline.tsx 使用独立拖选状态：左键按下记录起点，移动时按 15 分钟吸附并实时预览，松开生成起止范围；支持反向、跨日与横纵轴。Esc、pointercancel、窗口失焦取消。
- 单击保留默认 60 分钟入口，键盘 Enter／Space 保留默认安排；仅日期入口不改变。已有时间块移动与拉伸不触发新建面板。
- ScheduleDialog.tsx 将新建／已有任务编辑与排期同批提交；打开表单时固定数据版本，取消不写入，保存失败保留输入与错误提示。
- 保留原深浅玻璃布局和窄窗浮层详情；标签输入在前端及服务端均禁止 "/"。

## 验证与完成条件

- 自动测试覆盖多层双向完成传播、重新打开、移动父节点、循环拒绝、标签校验、迁移 ID 冲突、原始备份、旧提案失效、偏好映射、旧历史恢复、中断恢复和未采纳外部文件保护。
- 时间范围测试覆盖反向、最小 15 分钟与午夜边界；全量回归包含保存、审批、HTTP、冲突、历史及模拟 AI。
- 隔离浏览器验证横纵拖选、新建／关联与编辑、多选标签、刷新持久化、取消、跨日、单日／多日、窄窗、深浅主题，以及既有时间块移动／拉伸。
- 浏览器脚本与截图只保存在已忽略 .artifacts/，测试数据在 /tmp；不调用真实模型，不操作真实业务数据。
- 本轮采用 Context7 获取的 Playwright 官方鼠标 API 文档进行坐标验收。验证完成后本地提交，不推送。
