# v0.5.0 cli-ai-workflow 代码开发方案

## 文档的关键结论

AI 协作改为 CLI 对话，修改前展示差异并经聊天确认，日记允许全库检索后按需读取。网页保留手工管理与历史，不再配置或调用模型。

## 现状与设计

复用本机服务、harness、版本校验及历史。拆出上下文构建，移除供应商调用、聊天与模型设置接口；旧 secrets.json 不读取、不删除。业务数据版本保持 3，应用版本改为 0.5.0。

## 接口与实施

新增 harness confirm、proposals、proposal、documents、search。confirm 仅接受 harness 来源提案并记录 cli_confirmation；网页确认仍可用。列表和关键词搜索分页返回逻辑引用、标题及有限片段；日期条件仅匹配 daily 文档，正文按 read 读取。统一规则由 AGENTS.md 引导，其他 CLI 用导入文件共享。

先保存计划，再实现服务端与命令，移除网页入口，更新操作文档。保留已有未提交改动；本轮仅提交可安全隔离内容，不推送。

## 验证方法

专项测试确认权限、旧自动接受设置、冲突、幂等、部分失败、搜索分页及非法路径；运行全量测试、类型检查和构建。用临时目录和本机独立端口验证 CLI 与网页。日志、截图等放 /tmp 或 .artifacts，不提交。没有 ROADMAP.md，不创建 PROGRESS.md。

## 实施结果

已完成 CLI 确认、提案读取、日记分页检索、统一规则入口及网页模型能力移除。85 项自动测试、类型检查与构建通过；隔离数据验证 CLI 保存同步到网页、历史确认来源及日记上下文，网页背景编辑、回望、统计、提案、窄窗设置可用。Claude Code、Gemini CLI 未实机验收。验收产物留在 /tmp，不纳入 Git；无 ROADMAP.md，未创建 PROGRESS.md。

本轮暂存内容另导出到临时目录独立验证，79 项测试和构建通过；与用户原有未提交改动合并的当前工作区为 85 项测试通过。原有跟踪文件差异经逐行比较保持不变。
