# v0.4.0 statistics-dashboard 技术方案

## 文档的关键结论

沿用 React、TypeScript、现有快照与文件偏好存储，使用 SVG 绘制图表。新增统计纯函数与独立全宽视图，不新增服务端统计接口，不修改 workspace schemaVersion。

## 实现设计

- 统计模块输入工作区、日期范围、关注标签、当前时间，输出总览、逐日指标、标签汇总和核对明细。按任务合并区间，扫描工作区间端点计算并行；再计算时间窗口交集。
- 全量快照计算，与工作台显示筛选解耦；数据和配置更新即重算，页面打开时每分钟更新截点。
- Preferences 增加 statistics 对象，包含范围模式、自定义起止日期、关注标签 ID、隐藏图表键。旧偏好补默认值；继续使用 GET/PATCH /api/preferences。偏好完整子对象提交，服务端校验有效日期和起止顺序。
- 独立统计样式文件，复用主题变量；SVG 图表提供文字说明、焦点数值与图例，明细可展开。窄屏单列，表格内部横向滚动。
- 当前名称精确为“个人”的标签固定分析；关注标签按 ID 跟随改名，删除后提示重新选择。归档标签仍参与历史。
- 统计输出 `untaggedMinutes`，从裁剪后的无标签任务区间合并计算；前端仅在排行中加入“无标签”分类并统一排序、分页，不创建真实标签或改变关注标签选项。

## 白屏修复与折线趋势补充

当前开发服务出现新版前端与旧后端并存：偏好响应缺少 statistics，直接覆盖默认值后进入统计会抛出 range 读取错误。前端读取及保存偏好统一补齐缺失的统计默认值，并同步重启工作台后端；回归覆盖旧服务响应。

新增按日折线趋势，指标切换为工作、加班、午休占用、个人时长、并行占比与首次工作时间，一次显示一个指标，分别使用小时／百分比／时刻坐标。沿用全局日期范围、既有统计口径和图表显隐；缺失的占比及首次工作日期断开连线，零时长保留零点。首次工作和标签既有图表保留。指标切换为页面临时状态，不扩充持久化配置；新增图表显隐键 trend 由原偏好数组承载，旧偏好自然默认显示。

验收：旧后端白屏复现转绿，折线切换／断点／焦点数值／显隐正确，类型检查、全量测试及构建通过后记录结果。补充已完成：原日常环境点击统计的白屏已复现并修复，旧后端运行时也可正常打开；工作台开发服务已同步重启至当前代码。83项全量测试、类型检查与生产构建通过；额外验证趋势显隐保存的专项测试通过。浏览器验证六类折线、缺失日期断线、焦点数值、显隐刷新保持、空态及深浅主题／390px窄屏。此次局部修复与图表补充保留在工作区，未另行提交或推送。
