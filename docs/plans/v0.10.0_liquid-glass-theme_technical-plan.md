# v0.10.0 / liquid-glass-theme 技术方案

## 文档的关键结论

本次版本 v0.10.0，任务 liquid-glass-theme。复用现有 glass 呈现家族及共享控制器，新增独立主题定义、主题作用域材质和背景自定义抽屉，图片与模糊值通过现有偏好接口保存在本机，不新增依赖或重复业务视图。

- 新主题 ID 为 liquid-glass-light；前后端偏好类型与校验同步接入。
- 现有玻璃布局适用于本次需求；主题作用域确保原有主题不受材质覆盖影响。
- 无工作区数据迁移，不修改历史版本 schema，也不改变既有默认偏好。

## 实施

1. 注册主题 token，映射到 glass 呈现家族，扩展偏好枚举。
2. 在工作台、统计、待办样式中新增作用域规则；透明层使用弧面渐变、非对称内高光与窄边暗线表现玻璃厚度；按用户反馈采用中性白背景、0px 背景模糊。弹窗提高透明白底的覆盖率保证文字对比度，遮罩不再模糊背景。
3. 使用媒体查询保留减少动画及减少透明度支持；不支持 backdrop-filter 时使用实色表面。
4. 更新版本及 README；验证完成后精确暂存并本地提交，不推送。

## 验证

扩展现有主题持久化测试，验证重启后选择保留、其他偏好及工作区 hash 不变；运行完整测试和生产构建。使用独立端口及 .artifacts/liquid-glass 下隔离数据进行浏览器验证和截图，不操作正式数据。仓库无 ROADMAP.md，不创建 PROGRESS.md。运行产物目录已有忽略规则。

## 背景自定义接入

沿用现有偏好 PATCH 与原生 dialog 抽屉模式，不新增上传服务或依赖。新增可选 liquidGlass 配置，旧偏好补默认 { backgroundImage: null, backgroundBlur: 0 }。图片在浏览器解码、最长边缩放至 2560px 并转为 JPEG，输出 data URL 上限 140 万字符，连同模糊值保存至本机 preferences.json，保持在现有 2MB 请求限制内；单背景的简单存储优先于独立资源管理。

服务端限制 data URL 类型、JPEG 前缀、编码长度与字符，拒绝外链、SVG、非法模糊值及未知字段。背景独立图层仅在液态玻璃主题渲染，模糊时扩边避免露白。草稿在呈现层管理，取消丢弃，保存失败保留，切换主题不删除图片。图片处理期间禁止重复上传、关闭和保存，避免异步结果覆盖。

视觉以选定的 iPhone 控制中心与透明图标为参照：背景透过清透表面，边缘使用明暗高光表现弧面；内容区域维持必要白色衬底，避免复杂图片影响阅读。仍为网页近似材质，不宣称原生光学折射。增加配置边界及持久化测试，浏览器使用隔离数据验证上传和草稿生命周期。
