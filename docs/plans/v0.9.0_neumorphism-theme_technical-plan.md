# v0.9.0 / neumorphism-theme 技术方案

## 文档的关键结论

沿用现有共享控制器与独立呈现家族，在 presentations/neumorphism 注册第五个主题，不新增依赖。配置使用现有偏好接口持久化，预览仅保留在本主题页面状态中。

- 独立维护工作台和统计样式；共享待办通过主题作用域适配。
- 使用原生 modal dialog 实现右侧抽屉、键盘焦点约束及背景操作隔离。
- 本次版本 v0.9.0，任务 neumorphism-theme。保留工作区原有待办等修改，提交仅包含本次增量。

## 实施与数据

1. 新增主题配置类型、默认值及服务端范围校验；旧偏好缺失字段时补默认值。
2. 注册独立呈现，生成材质变量，适配三页面与弹窗。
3. 主题选择器支持旁侧入口及抽屉打开时锁定；抽屉草稿即时改变页面变量，保存成功才关闭。
4. 更新版本和使用说明，验证后本地提交，不推送。

配置约束：底色为浅色（各 RGB 通道至少 180），强调色自动选择黑白前景；圆角 8–32px，距离 2–12px，强度 0.05–0.25，模糊 6–36px，四角光源枚举。主要控件按比例使用阴影，避免密集区域阴影过重。

## 默认配置调整

客户端初始化与服务端新建偏好同步采用当前工作台配置；defaultNeumorphism 统一初始化、缺失字段补齐与抽屉恢复默认，defaultStatistics 使用本周范围。既有偏好不覆盖，旧文件的时间范围及父任务自动完成迁移默认保留兼容行为。沿用 v0.9.0，不新增版本；通过新建偏好、重启保留自定义配置、全量测试与构建验证。

## 行动清单的父子层次调整

父任务使用低位托盘包住所属子任务，二级、三级在父级容器内部逐层凸起。高低指视觉海拔，不压缩标题行高；任务行保留原有内边距、文字行高和操作入口。

拟态主题按现有筛选结果与树顺序嵌套呈现，每个容器包含自身任务行及下级容器。一级使用内阴影，二级使用柔和外阴影，三级及更深层使用较强外阴影；光源、距离与强度沿用主题配置。选中、完成和拖拽仍作用于自身任务行，避免父子点击冒泡；深层缩进继续设置上限。其他主题与业务数据不变。本次属于局部样式调整，不新增版本。

拟态设置增加 `rootRelief`：`inset`（凹陷，默认）或 `raised`（凸起）。旧偏好缺少该字段时补凹陷；凸起采用比二级更轻的外阴影，保持父低子高。配置沿用即时预览、取消恢复、保存和重置流程，仅影响行动清单一级容器。标签管理按钮保留完整的左右内边距和至少 36px 高度，日期筛选可收缩，避免窄侧栏挤压按钮。验证旧偏好兼容、保存与重启、预览取消、重置及窄侧栏布局。
