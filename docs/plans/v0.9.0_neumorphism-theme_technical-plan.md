## 文档的关键结论

沿用现有共享控制器与独立呈现家族，在 presentations/neumorphism 注册第五个主题，不新增依赖。配置使用现有偏好接口持久化，预览仅保留在本主题页面状态中。

- 独立维护工作台和统计样式；共享待办通过主题作用域适配。
- 使用原生 modal dialog 实现右侧抽屉、键盘焦点约束及背景操作隔离。
- 本次版本 v0.9.0，任务 neumorphism-theme。保留工作区原有待办等修改，提交仅包含本次增量。

## 实施与数据

1. 新增主题配置类型、默认值及服务端范围校验；旧偏好缺失字段时补默认值。
2. 注册独立呈现，生成材质变量，适配三页面与弹窗。
3. 主题选择器支持旁侧入口及抽屉打开时锁定；抽屉草稿即时改变页面变量，保存成功才关闭。
4. 更新版本和使用说明，验证后本地提交，不推送。

配置约束：底色为浅色（各 RGB 通道至少 180），强调色自动选择黑白前景；圆角 8–32px，距离 2–12px，强度 0.05–0.25，模糊 6–36px，四角光源枚举。主要控件按比例使用阴影，避免密集区域阴影过重。
